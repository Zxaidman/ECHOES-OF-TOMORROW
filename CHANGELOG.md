# Changelog

All notable project changes are documented here.

## [0.2.0] - Unreleased

### Added
- Initial Godot 4.7.2 project using typed GDScript and the Compatibility renderer.
- Settlement dashboard shell with six resources and five NPC profiles loaded from JSON.
- Integer-minute simulation clock.
- Strict JSON content loader with schema-version and stable-ID checks.
- Versioned JSON campaign snapshot save/load foundation.
- Dependency-free headless test runner.
- GitHub Actions headless validation workflow.
- Windows development build workflow publishing GitHub prereleases, never Actions artifacts.

### Notes
- This is a foundation build, not a complete playable simulation.
- Runtime validation and export verification must pass before this milestone is considered verified.
